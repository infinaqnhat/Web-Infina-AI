# Real Sale X — Landing Page Content & Layout Spec

> **Product:** Real Sale X (AI Deal Room) · **Market:** U.S. residential real estate · **Language:** English
> **Goal:** Product/lead-gen page (with nav) — drive **Book a demo** leads from ads + organic
> **Brand:** Infina system — Be Vietnam Pro, navy `#001F5C` / blue `#1863DC`, rounded cards, subtle motion (like `work.html`)
> **Primary CTA (repeat everywhere):** `Book a 15-min demo`
> **Status:** DRAFT for review — copy pulled from the pitch deck, to be confirmed.

---

## 0. Global elements

| Element | Spec | Best-practice note |
|---|---|---|
| **Nav** | Logo · links (AI Inside / AI Work / AI Personal / News) · **Book a demo** button (navy pill) | Keep nav lean; nav CTA = same action as page CTA. Sticky, blur bg (match site) |
| **Primary CTA** | `Book a 15-min demo` — repeated in hero, mid-page, final | Specific CTA beats "Get started" ~2×; one promise, one CTA |
| **Secondary CTA** | `See how it works` (ghost, scrolls down) | Muted so it doesn't compete |
| **Footer** | Infina footer (logo, links, © 2026) | Same as site |
| **Perf** | LCP < 2.5s, compress mockups, lazyload below-fold images | >3s bounce +38% |
| **Mobile** | Single column, form ≤3 fields, big touch targets, social proof stays above fold | ~71% B2B traffic is mobile |
