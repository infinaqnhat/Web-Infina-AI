# UI Spec — sync contract for `apps/infina-ai`

This folder is the **living UI/UX source of truth** for the marketing site in this repo.
It exists so that when the HTML here changes, the change can be handed to the production
Nx app (`apps/infina-ai` in `/Users/ngocthien0507/Thien/infina/infina-ai-apps`) as a
precise, reviewable diff — not a "go re-eyeball the site" request.

## What's here

| File | Content | Maintained by |
|------|---------|---------------|
| `_tokens.md` | Shared design-token baseline (from `home.html` `:root`) | **AUTO** — `npm run spec` |
| `<page>.md` | Per page: token overrides, section inventory, headings/CTA/assets | **AUTO** zone |
| `<page>.md` | Nx component/route mapping + design-intent notes | **MANUAL** zone (hand-written) |

Scope = 7 live canonical pages: `home, work, inside, personal, about, focus-alignment, salesx`.
Excludes `work-old.html`, `salesx-v2.html` (experiments).

## Two zones per file — do not mix

Each `<page>.md` has an **AUTO zone** between the markers:

```
<!-- AUTO:START — regenerated by `npm run spec`. Do not edit below. -->
   … regenerated from the HTML — never hand-edit …
<!-- AUTO:END -->
```

Everything **outside** the markers is the MANUAL zone (Nx mapping, design intent). The
generator rewrites only the AUTO zone and leaves the MANUAL zone byte-for-byte intact, so
your hand-written notes survive every regeneration.

## Commands

```bash
npm run spec            # regenerate AUTO zones in existing spec files
npm run spec:scaffold   # create any MISSING spec files (skeleton) then regenerate
npm run spec:check      # exit 1 if any spec is stale — for pre-commit / CI
```

## Sync workflow

1. Marketing edits the HTML (e.g. `work.html`).
2. Run `npm run spec` → AUTO zones update.
3. `git diff docs/ui-spec/` → the precise changeset (no HTML/whitespace noise).
4. If a section was added / renamed / removed, update that page's **MANUAL zone**
   (Nx mapping row + design intent).
5. Commit.
6. When the Nx side is updated to match, bump the marker below to the synced commit.
7. To brief the Nx agent, hand it: the changed `docs/ui-spec/<page>.md` file(s) **plus**
   `git diff <last-synced-sha>..HEAD -- docs/ui-spec/`. It reads the mapping table to know
   which React component/route to edit.

## Adding a new page

Add its basename to the `PAGES` array in `scripts/extract-ui-spec.mjs`, then run
`npm run spec:scaffold`. Fill the new file's MANUAL zone.
